## Findings
- 2026-10-13 first boot (stock OpenNative, game imported to /storage/emulated/0/Android/data/<pkg>/CustomGames): launch killed the app.
  Cause: Android's MediaProvider FUSE daemon aborted twice (`NodeTracker::CheckTracked` in `pf_opendir`) while Wine scanned the game dir.
  FUSE death kills every app with open files there and resets USB (adb dropped). Fix: keep game files in app-internal storage (dataDir/CustomGames, already a scan root). Also faster I/O.
- 2026-10-13 boot from internal storage: no more FUSE crash. Two hangs:
  - FEX/ARM64EC (proton-10.0-arm64ec-2): stops right after `libarm64ecfex.dll` loads; no further DLL loads; 80% CPU, 62 MB RSS.
  - Box64 0.4.2 (proton-9.0-x86_64): loads steam_api64 (Goldberg), fmod, bink, winex11, uxtheme, then spins on 1 core at 100%; RSS flat 191,736 KB for 3+ min; no window, d3d11 never loads.
  - Goldberg `disable_networking.txt` + `offline.txt` added: no change (Android blocks netlink: `nsi:poll_netlink bind failed, errno 13`).
  - Next: run the same folder under Wine in WSL (real x86) to split Android-specific vs Wine/exe issue.
- 2026-10-13 ROOT CAUSE of startup hang (simpleperf on the spinning thread): a SIGSEGV storm in `shim_segv_handler` (libredirect-bionic-wx.so) + sigprocmask.
  The "modern" flavor targets SDK 36 → Android W^X rules → DSR's anti-tamper writes into its own code pages → fault → shim resumes → fault again, forever.
  Interpreter (BOX64_DYNAREC=0) hung identically, which ruled out the JIT. Winlator works because it targets SDK 28.
  Fix: use the `legacy` flavor (targetSdk 28, libredirect-bionic.so, no W^X).
- 2026-10-13 20:31 FIRST BOOT: title screen reached. Working config: legacy flavor (targetSdk 28), Box64 0.4.2 COMPATIBILITY preset, proton-9.0-x86_64 (bionic), DXVK 2.4.1-gplasync, Turnip v26.2.0 R4 wrapper, 1280x720. ~1.2 GB RSS at title.
  FEX/ARM64EC still loops in exception handling (ill_handler/usr2_handler in ntdll) on the anti-tamper — Box64 is the base for now.
- 2026-10-13 perf baseline (Box64 COMPATIBILITY, all 8 cores): title 60 FPS; gameplay (Undead Burg stairs, PC save) **11 FPS**, CPU 36%, GPU 24%.
  Threads: main 75%, 2x MOMainThread 31%, HighGraphics 28%, dxvk-cs 22%. Phone RAM 10.9/11 GB used + 4 GB swap.

## Goal
Everything we learned is reusable: the next game starts from the generic guide, and other DSR owners can apply our edits to their own copy.

## Repo layout (proposal)
```
README.md                    what it is, legal note (bring your own game), quick start
docs/PORTING_GUIDE.md        generic PC game -> Android APK recipe (from PORTING_LOG §6 + day-2 lessons)
docs/PORTING_LOG.md          full history: what worked, what failed, mistakes
docs/dsr/RE_NOTES.md         offsets + method used to find each
docs/dsr/PERFORMANCE.md      timescale fix, Box64 flags, thermal data, benchmarks
docs/dsr/CONTROLS.md         touch layer + UI mods (later)
mod/dinput8/                 in-game agent (dinput8.dll proxy) source + build script
tools/                       bench, probes, memtool, RE scripts
app/ (submodule or branch)   OpenNative fork, branch dsr
```
Excluded: game folder, saves_backup/, steam_settings/, any exe/dll from the game.

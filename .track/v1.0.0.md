## Goal
User request 2026-10-15: at release, all our changes ship as a mod set plus a small program that applies it to a bare game copy, so anyone who owns the game can port it themselves. Builds on v0.5.0 (public code + apply-it-yourself guide).

## Change manifest (what the patcher must reproduce)
Game folder (user's bare v1.04 copy):
- `dinput8.dll` = our agent (mod/dinput8): tick/governor/pacer, input caches, event pool, LOD, HUD hiding (hud.c). Installed by the app on every start.
- `dsr_assets/` = `tools/extract_assets.py <game> <out>`: icons/*.png, items.json, prompts.json, text.json (from the user's own files, never shipped).
- Goldberg Steam emulator files (steam_api64.dll + steam_settings) — the user's own setup; document, never ship.
- `menu/menu.drb.dcx` = `tools/patch_menu.py <game>`: souls box top-left, quick item name under the Estus slot (stock kept as `menu.drb.dcx.orig` on the phone).
  Also: main menu as one row of 5 (T00-00 rows/cursors, font 11), HUD group right of the Estus slot.
- Agent `title.c`: title entry table 0x141a32250, Log In (text 0x61f9a) action 5 -> 7 (hidden); "TOUCH TO START" text; tap-to-pick entries (dsr_title.txt / dsr_title_dlg.txt).
- Agent `cam.c`: follow cam speed x1.5. Agent `hud.c` menu_hud: HUD option forced off while a menu is open.
- menu.drb.dcx also: menus centred, key-guide lines hidden, game tab strip hidden (icons invisible, still clickable), bigger System list / item menu rows.
- `dsr_assets/ui/` = extract_assets.py UI_PIECES (slot_bg, lineframe, plate, parchment) for the game-style controls.
Prefix:
- `AppData/Local/FromSoftware/NBGI/DarkSouls/DarkSouls.ini`: WindowMode=2, Width/Height = X screen size (app, `DsrLauncher.writeDisplayIni`, every start).
Save:
- Quit flag cleared before each launch (app, `DsrLauncher.clearQuitFlag`; format in tools/sl2.py).
App/container (APK): DSR mode, Box64 env (ContainerUtils), WINEDLLOVERRIDES=dinput8=n,b, 30 FPS limiter, touch layer, startup notice auto-OK.
